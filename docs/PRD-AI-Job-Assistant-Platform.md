## 一、产品概述

### 1.1 项目背景

当前求职市场面临以下痛点：

| 痛点 | 具体表现 |
|------|----------|
| 简历针对性差 | 求职者不会根据岗位要求调整简历，"一份简历投遍天下" |
| 技能认知模糊 | 不知道自己有哪些技能，无法准确描述能力 |
| 经历挖掘不足 | 工作经历、项目经验不会包装，亮点被埋没 |
| 面试准备盲目 | 不知道面试会问什么，缺乏系统性准备 |
| 效率低下 | 手动修改简历耗时耗力，效果不佳 |

### 1.2 产品定位

**一款基于 AI 的智能求职助手平台**，通过 AI 技术帮助求职者：
- 智能解析岗位要求
- 深度挖掘个人技能与经历
- 一键生成岗位定制简历
- 制定个性化面试准备方案
- 提供沉浸式模拟面试体验

### 1.3 核心价值主张

```
岗位截图/链接 → AI 解析要求 → 技能匹配 → 简历生成 → 面试准备 → 模拟面试
     ↓              ↓            ↓           ↓           ↓           ↓
   一键导入      精准识别      智能推荐    定制输出    针对性方案   实战演练
```

### 1.4 目标用户

| 用户群体 | 特征描述 | 核心诉求 |
|----------|----------|----------|
| 应届毕业生 | 缺乏工作经验，不知道如何包装实习/项目经历 | 挖掘校园经历亮点，生成专业简历 |
| 职场转型者 | 想转行/转岗，担心经验不匹配 | 技能迁移分析，突出可迁移能力 |
| 资深职场人 | 经验丰富但不会提炼，简历冗长 | 精准筛选相关经历，突出核心价值 |
| 被动求职者 | 时间有限，需要高效工具 | 快速定制，批量优化 |

### 2.2 模块一：岗位智能识别

#### 功能描述
用户通过截图或分享链接导入目标岗位，系统自动解析并结构化岗位要求。

#### 输入方式

| 方式 | 说明 | 支持平台 |
|------|------|----------|
| 截图上传 | 上传招聘信息截图，OCR识别 | Boss直聘、猎聘、拉勾、智联、51job、LinkedIn等 |
| 链接分享 | 粘贴岗位链接，自动抓取 | 主流招聘平台 |
| 手动输入 | 复制粘贴岗位描述文本 | 任意来源 |

#### 匹配算法逻辑

```python
def generate_resume(job_requirement, user_profile):
    """
    简历生成核心逻辑
    """
    # 1. 提取岗位关键词
    job_keywords = extract_keywords(job_requirement)

    # 2. 技能匹配度计算
    matched_skills = match_skills(job_keywords, user_profile.skills)

    # 3. 经历相关性排序
    ranked_experiences = rank_by_relevance(
        user_profile.experiences,
        job_requirement
    )

    # 4. 内容取舍（控制在一页内）
    selected_content = select_content(
        matched_skills,
        ranked_experiences,
        max_length=ONE_PAGE
    )

    # 5. 表述优化
    optimized_content = optimize_wording(
        selected_content,
        style="professional"
    )

    return generate_document(optimized_content, template)
```

### 4.3 关键算法

#### 4.3.1 岗位-简历匹配算法

```python
def calculate_match_score(job_requirement, user_profile):
    """
    计算岗位匹配度
    """
    scores = {}

    # 1. 技能匹配 (权重 40%)
    skill_score = calculate_skill_match(
        job_requirement.skills,
        user_profile.skills
    )
    scores['skill'] = skill_score * 0.4

    # 2. 经验匹配 (权重 30%)
    experience_score = calculate_experience_match(
        job_requirement.experience_years,
        user_profile.total_years,
        job_requirement.industry,
        user_profile.industries
    )
    scores['experience'] = experience_score * 0.3

    # 3. 项目相关度 (权重 20%)
    project_score = calculate_project_relevance(
        job_requirement.keywords,
        user_profile.projects
    )
    scores['project'] = project_score * 0.2

    # 4. 软技能匹配 (权重 10%)
    soft_skill_score = calculate_soft_skill_match(
        job_requirement.soft_skills,
        user_profile.soft_skills
    )
    scores['soft_skill'] = soft_skill_score * 0.1

    return sum(scores.values()), scores
```
